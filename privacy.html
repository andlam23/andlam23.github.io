Privacy policy

Last updated: 23 November 2026.

This policy covers Stock Image Fight Uploader, the upload tool of the YouTube channel Stock Image Fight.

What the tool accesses

With the channel owner's sign-in through Google, the tool uses the YouTube Data API to upload the channel's own videos and to set their titles, descriptions, thumbnails, playlists and publishing times. It acts only on the Stock Image Fight channel and posts nothing anywhere else.

What it does not do

  • It does not read, collect or store data about viewers or any other YouTube user.
  • It does not share, sell or transfer any data to anyone.
  • It is not offered to the public: only the channel owner signs in to it.

Where its data is kept

The sign-in token is kept only on the channel owner's own computer, and is used only to make the uploads above. The owner can withdraw the tool's access at any time at myaccount.google.com/permissions.

Deleting data

Besides the sign-in token, the tool keeps only a record on the owner's computer of which of the channel's own videos it uploaded (their video ids), so that it never uploads a video twice. When access is withdrawn, the owner deletes the token and that record from the computer; the tool then holds no data at all. Data about the channel's videos stays with YouTube and can be deleted in YouTube Studio.

YouTube API Services

The tool uses YouTube API Services. Its use of them follows the YouTube Terms of Service and the Google Privacy Policy.

Contact
